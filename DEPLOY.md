# Deploy (No Actions)

This project publishes with GitHub Pages from the `gh-pages` branch.

## One-command deploy

From repository root, run:

```bash
bash deploy-pages.sh
```

## What it does

1. Verifies your working tree is clean.
2. Switches to `gh-pages`.
3. Merges latest `main`.
4. Pushes `gh-pages` to origin.
5. Returns to your original branch.
